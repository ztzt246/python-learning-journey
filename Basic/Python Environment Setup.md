python安装完毕后，打开CMD（win+R）输入python，即可进入python解释器

![打开 Python 解释器](../images/python-cmd.png)

离开python

![离开 Python 解释器](../images/exit-python.png)

基本语法
  print("输出内容")

运行长段代码
  1.创建文本文件,并更改后缀为.py
  2.exit()退回到win系统中
  3.cd /d 路径 ##告知路径
  4.python 文件名.py //注意:如果这一步找不到文件,那么打开资源管理器>查看>显示>文件扩展名,看看是不是仍然是.txt文件
